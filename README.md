# 문서사이

수학 문서를 위한 한글 · LaTeX · Word 변환기.

- 웹사이트: https://hyunjae-lee.com/document-between/
- GitHub Pages: https://loveoneanother12.github.io/document-between/
- `index.html`: 브라우저에서 실행하는 단일 HTML. 파일은 기기 안에서 처리합니다.
- `source.zip`: 변환기 소스와 테스트. 압축을 풀고 `npm ci`, `npm test`, `npm run build`로 빌드합니다.

한글 → LaTeX, 한글 → Word, LaTeX → 한글, Word → 한글, Word → LaTeX를 지원합니다. 원본과 변환 결과의 수식, 문서 배치는 사용 전 확인해 주세요.
